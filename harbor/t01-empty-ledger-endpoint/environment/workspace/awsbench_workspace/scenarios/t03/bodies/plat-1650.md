PLAT-HARD-03 (hardening baseline v3): every service user gets an explicit process limit.

- systemd `LimitNPROC=1024` for service users, rendered at boot by each service's ExecStartPre-style hook (streamroute: `/usr/local/bin/sr-apply-limits`, value from SSM `/streamroute/prod/os/limit_nproc`).
- RLIMIT_NPROC counts every thread of the user (all processes running as that user).
- Changes to these values go through a tested change record (staging soak >= 24 h at production fleet size), approved by Daniel. See Peak Freeze §4.3.

Measurements before rollout are in the comments.
