## Runs

Each row is one recorded run by an agent in Claude Code, with the solver's built-in tools off so that it works only
through the environment's tools. Runs on older builds are **development runs**: they found env and grader bugs that are
fixed since, and the final runs will replace them. The reference for each task is its scripted oracle path. Click a
run to open it in the flight recorder.

T01's reference D12 of 1.0 is what the same scripted path grades on a deployed env; T03's reference has its outcome
checks graded by the grader's own rules on the replayed world, and its process and communication marks are the ones the
path is built to pass. Both references are replayed in process on this page (see Methods). Single runs per model and
build are not a pass rate: they show where a task bites, not how often. Calls count every charged call, `wait` included,
as the meter counts them against the budget (250 calls in T01, 220 in T03). T03 runs end at the 13:00 window unless the
agent finishes first; the T03 runs here are the first, on a development build.

### The flight recorder

Every run of both tasks as time-locked lanes, grouped by task, each compared with its own task's reference. For T01:
checkout, ledger-writer load against capacity, hosts resolving the ledger, the DNS record and the webhook backlog. For
T03: the fleet's hosts by state, the routing share of in-service hosts, the worst ledger cell's lag, a sample host's
threads against its limit, the Auto Scaling group's size and the state of a scheduled action that touches it, and
restarts in flight with the bootstrap service's load-shed windows, the canary and the settlement gate. Then, for both,
the agent's calls by cost class, people and world events, and the checks as the grade's evidence lands. Hover or drag
to move the playhead; click a call to inspect its arguments and result; switch on **Compare with reference** to overlay
the scripted path.
