## Runs

Each row is one recorded run of T01 by an agent in Claude Code, with the solver's built-in tools off so that it works
only through the environment's tools. Runs on older builds are **development runs**: they found env and grader bugs
that are fixed since, and the final runs will replace them. The reference is the scripted oracle path.

The reference's D12 of 1.0 is what the same scripted path grades on a deployed env; on this page its world is replayed in
process (see Methods). Single runs per model and build are not a pass rate: they show where the task bites, not how
often.

### The flight recorder

Every run as time-locked lanes: checkout, ledger-writer load against capacity, hosts resolving the ledger, the DNS
record, the webhook backlog, the agent's calls by cost class, people and world events, and the checks as the grade's
evidence lands. Hover or drag to move the playhead; click a call to inspect its arguments and result; switch on
**Compare with reference** to overlay the scripted path.
